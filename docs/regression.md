# 回归测试清单（守卫优先 · 状态链式）

> 依赖关系：ADB 即时开关（无依赖）→ 被动守护（仅 root，无需重启）→ 用户意志（需守护 + 重启）→ 主动守护（需 LSPosed + 重启）→ 开机自启（需重启）。阶段 8 卸载清理最后跑。
>
> 每个开关"一进一出"，关掉后立刻接着做"关闭后"的延续测试，上一个测试的结束状态 = 下一个测试的开始状态。全程同时观察 UI（阶段 7）。
>
> **关键区分**：App 内无线 ADB 开关 = 用户最高意志（关→写 intent file→守护不拉回）；系统开发者选项关无线调试 = 外部关闭（不写 intent file→守护 10s 拉回）。测守护"拉回"必须用开发者选项关。
